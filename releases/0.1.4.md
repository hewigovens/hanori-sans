The fonts are unchanged apart from the version. This release adds the first notarized build of the Preview app and the Safari reading extension inside it.

## Preview app

A universal macOS app (Apple Silicon and Intel, macOS 14+) for previewing the four fonts, with **Install Fonts…** to add them through Font Book. Install with Homebrew:

```sh
brew install --cask hewigovens/tap/hanori-preview
```

Or unzip `HanoriPreview-0.1.4-macos-universal.zip` and move the app to Applications.

## Reading extension

The app embeds a Safari extension that shows readings above kanji on Japanese webpages. Font mode switches the page to a Hanori Furigana font; Accurate mode analyzes the text on your device and lets you save corrections. Turn it on in Safari → Settings → Extensions. The same extension for Chrome and Edge is distributed through the Chrome Web Store and falls back to Accurate mode when the fonts are not installed.

## Fonts

Hanori Sans, Hanori Sans Furigana, Hanori Serif, and Hanori Serif Furigana as static Regular-weight OpenType fonts, with the upstream licenses and attributions.

```sh
brew install --cask hewigovens/tap/font-hanori
```

Or unzip `Hanori-0.1.4.zip` and install the `.otf` files with Font Book.
